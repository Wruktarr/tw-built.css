## tw-built.css
Tailwind built using npm.

**Usage:**

```html
<link rel="stylesheet" href="https://raw.githubusercontent.com/Wruktarr/tw-built.css/refs/heads/tw-built/<version>/tw-built.min.css" type="text/css">
```

<sub><sup>Notice: This usage of Tailwind should be only used for testing purposes as css is not adjusted automatically to your code needs.</sup></sub>
